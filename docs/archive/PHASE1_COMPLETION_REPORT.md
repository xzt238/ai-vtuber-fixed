## 🎯 技术实现

### 1. RAG知识库架构

```
文档导入 → 文档解析 → 文本分块 → 向量化 → 存储
                                          ↓
用户查询 → 向量化 → 检索相似块 → 上下文组装 → LLM生成
```

### 2. 跨平台架构

```
┌─────────────────────────────────────────────┐
│              应用层                          │
├─────────────────────────────────────────────┤
│  PySide6/Qt6 │ 原生桌面 │ 浏览器模式        │
├─────────────────────────────────────────────┤
│              平台抽象层                      │
├─────────────────────────────────────────────┤
│  Windows │ macOS │ Linux                    │
└─────────────────────────────────────────────┘
```

### 3. 核心组件

#### RAG知识库组件
- **文档加载器**: 支持多种文档格式
- **文本分块器**: 智能分块，保持语义完整性
- **检索器**: 向量检索+关键词检索
- **生成器**: 检索增强生成
- **知识库管理**: 文档管理、统计、查询

#### 跨平台组件
- **平台抽象层**: 封装平台差异
- **启动脚本**: 跨平台启动支持
